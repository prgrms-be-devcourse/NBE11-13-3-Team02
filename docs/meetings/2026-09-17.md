## 논의

### 도커 전환

- 이석우: 전체 스택을 docker-compose로 띄우도록 정리함. `./run-docker-full.sh up -d --build`
  하나로 MySQL·Redis·core·프론트·Prometheus·Grafana·챗봇 7개가 뜬다.
- 처음엔 챗봇이 compose에 빠져 있었는데 이석우가 Dockerfile 만들어서 넣음. 프론트가
  컨테이너 안에서 `chatbot:8000`으로 바로 부른다.
- 안서호: 챗봇 Dockerfile에 `.dockerignore`가 없어서 `.env`가 이미지에 통째로
  구워지고 있었다. JWT_SECRET이랑 GEMINI_API_KEY가 들어 있는 파일이라 이미지만
  있으면 꺼낼 수 있는 상태였음. `.dockerignore` 추가해서 막음.
- `docker compose`를 직접 쓰면 JWT_SECRET 없다고 거부당한다. 반드시 래퍼 스크립트로
  실행해야 한다는 걸 팀에 공유하기로 함.

### 대기열 Lua 스크립트 누락으로 결제가 막혔던 건

- 대기열을 core 안으로 되돌리면서(97ee3c3) Kotlin 코드만 옮기고 Redis Lua 스크립트
  6개가 빠졌다. `redis/queue-enqueue.lua` 외 5개.
- 증상은 "결제창이 안 뜨고 서버 내부 오류". 대기열 토큰 발급이 500이 나서
  결제창을 여는 코드에 닿기도 전에 죽었다.
- 원인 찾는 데 오래 걸린 이유가 있다. GlobalExceptionHandler의 catch-all이 예외를
  받아놓고 로그를 안 남겨서, 500이 났다는 사실 말고는 아무 단서가 없었다.
  로깅을 넣자마자 바로 나왔다. 이석우도 같은 수정을 따로 하고 있었음.
- 이석우가 PR #10으로 Lua 6개 복구. 확인 결과 결제 흐름 정상 동작.

  원인을 찾기 어렵다. 실패를 잡아 멈추는 검사를 넣을지 이석우가 판단하기로.
